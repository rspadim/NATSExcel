NATSExcel

Add-in do Excel (XLL) que traz o NATS para dentro do Excel por meio de RTD (Real-Time Data) e UDF (funções definidas pelo usuário): você digita uma fórmula, o dado do NATS chega na célula e — nas funções de streaming — fica ao vivo.

Cobre o NATS Core (pub/sub, request/reply, grupos de fila, headers) e o JetStream (streams, consumidores, replay, Key/Value Store, Object Store). Construído com Excel-DNA sobre o .NET Framework 4.8, usando NATS.Net, NLog e Newtonsoft.Json.

Requisitos

  • Windows com Microsoft Office (Excel), 64 bits ou 32 bits.
  • .NET Framework 4.8, que já vem no Windows 10 e no Windows 11.
  • Um servidor NATS para conectar. O instalador consegue subir um nativamente no Windows; Docker é opcional e nunca obrigatório.

O que ele faz

Instalação

  1. Execute NATSExcelSetup-<versão>.exe. Ele copia o add-in, detecta a arquitetura do seu Office, escreve um NATSExcel.json inicial e (se você quiser) sobe um servidor NATS para você.
  2. Abra o Excel. O add-in se registra sozinho, então o XLL carrega automaticamente. Se não carregar, habilite à mão em Arquivo → Opções → Suplementos → Gerenciar: Suplementos do Excel → Procurar….
  3. Conecte: edite o NATSExcel.json (ou use o assistente do instalador). O padrão é nats://localhost:4222.

Ainda não tem servidor NATS? O instalador consegue rodar um nativamente no Windows (um único nats-server.exe, com JetStream incluído). Docker é opcional, nunca obrigatório.

Veja funcionando

=NatsUDFVersion()                                        ' o add-in responde
=NatsUDFPublish("orders.new","hello")                    ' publish no Core
=NatsUDFSubjectLatest("orders.new")                      ' lê o último valor
=NatsUDFKVPut("config","rate","1.23")                    ' escrita no Key/Value
=RTD("NatsRtd",,"SUB","orders.>")                        ' uma célula ao vivo

Privacidade

O NATSExcel não coleta nenhum dado do usuário. A única requisição que ele faz por conta própria é uma chamada em segundo plano à API de releases do GitHub, para verificar se existe uma versão mais nova; o resultado fica em cache e falhas (offline, limite de requisições) são ignoradas. Ele grava um arquivo de log local (NATSExcel.log) ao lado dos próprios arquivos. O tráfego NATS vai apenas para o(s) servidor(es) que você configurar. A checagem de atualização pode ser desligada com UpdateCheck: false no NATSExcel.json.

Suporte e contribuição

Dúvidas, relatos de bug e pull requests são bem-vindos em github.com/rspadim/NATSExcel. Ao abrir um bug, inclua a versão do add-in (=NatsUDFVersion()), a arquitetura do seu Office e se o servidor tinha JetStream ativado.
